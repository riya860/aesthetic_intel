- Fetch available saved Boulevard reports

Installation:
1. Extract inside public_html with Replace existing files.
2. Do not run install.php.
3. Refresh with Ctrl+Shift+R.
4. Open a business as Super Admin.
5. Tools → Boulevard → API Integration.
