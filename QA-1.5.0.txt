Safety behavior
- Existing monthly KPI values cannot be replaced without explicit confirmation.
- Every completed Phase 3 import stores a rollback snapshot.
- Only the latest completed import can be rolled back.
- Rollback is blocked if any affected KPI value changed after that import.
- Rollback is limited to Leadership/Super Admin access.
- All import and rollback writes use database transactions.
- Provider profiles created during a rolled-back import are preserved to avoid deleting profiles that may have been used after creation.
- Existing users, providers, goals, imports, reviews, actions, reports, credentials, and uploaded data are not deleted by the patch.
