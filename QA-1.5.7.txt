Permission / AI safety checks
- Smart Search starts from documentation_visible_topics(), so unauthorized features are removed before ranking and before AI fallback.
- AI fallback receives no more than five authorized candidates.
- AI prompt allows only supplied candidate IDs and explicitly forbids executing actions.
- AI output is server-validated against allowed candidate IDs before use.
- Destination URLs come only from the internal Documentation registry, never from AI output.
- Smart Search has no delete/update/settings execution route of its own.
- POST search is CSRF protected.
- Smart Search requires authentication.
- AI/API failure does not block search; local results remain available.

Token / privacy checks
- High-confidence searches never call OpenAI.
- AI fallback is only used for uncertain local matches.
- AI payload contains compact feature metadata only, not full Documentation/codebase/report data.
- Cache uses hashed normalized intent rather than raw search text.
- Cache does not store AI explanation text or user query text.
- Audit records query length/mode only, not raw query content.

Cache / migration checks
- smart_search_cache is created with IF NOT EXISTS.
- Cache key includes normalized intent, current permission/module context, candidate signature, and prompt version.
- Candidate/permission changes invalidate old routing naturally through a new hash.
- Cache failure is fail-open for navigation: Smart Search continues without caching.
- Fresh-install database/schema.sql includes smart_search_cache.
- Existing installations receive the table through app/migrations.php.
- No install.php execution is required.

Deployment security
- Release delta excludes config/database.php.
- Release delta excludes config/app-key.php.
- Release delta excludes config/boulevard-worker-key.php.
- Release delta contains no uploaded reports, business logos, backups, sessions, runtime logs, or stored credentials.

Live-environment note
- No production OpenAI request was executed during offline package construction.
- Clear searches were tested through Layer 1 locally.
- Low-confidence AI fallback will reuse the existing configured OpenAI integration on Hostinger.
