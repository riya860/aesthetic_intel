IMPORTANT BACKWARD-COMPATIBILITY NOTE
=====================================

Existing generated reports created under the old schema do not contain visualizations.
They will still render normally. Charts only appear after a report is regenerated with the new prompt/schema.

No database migration is required because visualizations are stored inside the existing generated_json column.
The current source snapshot, source hash, version history, publish flow and audit logging remain unchanged.

LOCAL TEST PLAN
===============

1. Start the local Aesthetic Intel project as normal.
2. Sign in as Super Admin.
3. Ensure AI Weekly Report is enabled for the test business.
4. Go to AI Weekly Reports > Generate New Weekly Report.
5. Select a business and a period that has validated source data.
6. Refresh Source Data.
7. Save / Generate the report using the existing flow.
8. Open the private preview.
9. Confirm:
   - Hero animates in.
   - KPI cards reveal progressively.
   - Charts animate when supported data exists.
   - Wins/Risks/Opportunities render correctly.
   - Recommendation rationale expands/collapses.
   - Source coverage matches the selected source period.
   - Dark mode updates chart colors.
   - Mobile layout stacks correctly.
10. Publish the report.
11. Switch to the business dashboard and open the published report.
12. Confirm the same reusable dashboard renderer appears.
13. Test Print / Save PDF.

CHART SAFETY RULES
==================

- No fake chart data.
- No interpolation of missing periods.
- No line chart unless ordered historical/time data exists in the source snapshot.
- No mixed-unit datasets in the same chart.
- Chart labels and values must align exactly.
- If truthful graph data is unavailable, the visualizations array is empty and the dashboard simply renders without charts.

DEPENDENCY
==========

The page-specific JS lazy-loads Chart.js 4.4.7 from jsDelivr only when a report contains chart data.
If you later want a fully self-hosted dependency, download the UMD build into assets/js/vendor/ and update CHART_JS_URL in assets/js/ai-weekly-report.js.
